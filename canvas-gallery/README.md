# Lum 画布作品库

在 Lum 的画布工作流中，点击底部「帮助」右侧的「画布分享」。选择作品即可预览布局、连线和节点内容。首个收录作品是[《末班车 · 开场分镜》](works/last-bus.json)。

## 下载与导入

「下载分享文件」会保存一份可传给其他使用者的 JSON。在「画布分享 → 打开分享文件」中可以离线预览。点击「导入为副本」会把作品保存为当前项目下的新画布，可以从画布菜单打开继续编辑。

## 投稿

1. 在「分享当前画布」填写作品名称和公开署名。按需勾选正文、剧本、分镜和提示词。
2. 点击「生成本地预览」，核对节点、连线、即将公开的文字及转换说明。要分享生成结果，可按节点勾选图片、视频或音频，再点「更新附件预览」查看最终作品。未勾选的媒体留在本机。剧本和分镜以文字副本分享。
3. 在投稿区使用自己的 GitHub 账号提交。可以下载投稿 JSON，在自己的公开 fork 中上传至 `canvas-gallery/works/` 并发起 Pull Request。也可以在 Lum 中使用本次投稿的 GitHub 令牌，由软件创建分支、上传文件并申请审核。
4. 维护者在 Pull Request 的 **Files changed** 查看作品。可以下载 JSON，在 Lum 内预览后合并。合并到 `main` 后，打开作品库并点击「刷新作品」即可看到新作品。公开 fork、分支或 Pull Request 中的文件在审核前已可被他人访问。

每个作品使用一个 UTF-8 JSON 文件。用 Lum 导出的投稿文件名可避免重名。作品最多 20 MiB，单个媒体文件最多 10 MiB，支持 500 个节点和 2,000 条连线。提交时只包含自己有权公开的内容。
