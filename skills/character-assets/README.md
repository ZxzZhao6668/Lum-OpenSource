# 人物资产 Skill 包

三套均已内置到画布的“技能”页，默认仅分配“人物生图”。人物资产的“生成资产图片”窗口里可直接选择。既有默认 Skill 保留，不需要重复导入。

| Skill | 推荐生图比例 | 画面内容 |
| --- | --- | --- |
| 人物资产 · 竖版四宫格 | 3:4（可用 2:3） | 左上正脸特写、右上45°侧脸特写；左下无头正面身体至脚底、右下完整背面全身 |
| 人物资产 · 竖版五宫格 | 2:3（可用 3:4） | 上2下3：左上正脸特写、右上45°侧脸特写；左下无头正面身体、中下完整侧面全身、右下完整背面全身 |
| 人物资产 · 横版标准设定 | 16:9（可用 3:2） | 一行四栏：脸部特写、正面全身、纯侧面全身、背面全身 |

这些排版和比例是针对本画布流程的设计选择，不是行业强制规格。人物图片生成模型对严格宫格数量和跨视图一致性的执行能力各有不同，规则不能保证每次生成完全符合要求。

## 使用

1. 进入人物资产，填写已有的外貌、服装、配饰资料，打开“生成资产图片”。
2. 选择需要的 Skill，在单次生成窗口选对应比例和模型支持的分辨率。四宫格可以先用 2K；需要更清晰面部和服装细节时，可选模型支持的 4K。
3. 已经有满意的人物定稿图时，勾选“使用当前资产图片作参考”；首次设计没有参考图也可使用，不会伪造图片引用。
4. 补充要求示例：“延续现有人物身份与服饰，浅灰背景；保留人物自身左肩银扣，不增加武器；各格按 Skill 指定位置与裁切生成。”两套竖版的左下正面身体图按颈根/肩线至脚底取景，头部在画框外；侧面与背面全身图保留头部。避免补充“所有格头脚完整”这类与指定裁切冲突的要求。
5. 点击“AI 优化提示词”，检查各格位置、服装、配饰左右关系，然后再点击“生成图片”。
6. 选用满意结果后，关联分镜继续使用这份人物资产图。检查重点是换脸、换装、错位配饰、重复视角、缺格、多格、裁掉双脚或把无头裁切错用到其他格。

Skill 本身不更改统一比例、分辨率或模型配置。建议在单次生成面板调整人物设定图的画幅，避免把整个项目的分镜比例一并改成竖版。提示词优化只生成文字；最后一次“生成图片”仍由你点击。

2026-11-06 按用户指定更新两套竖版布局。刷新软件后选择相应 Skill，重新点击“AI 优化提示词”再生成；旧提示词草稿和已生成图片不会自动改版。

## 导入文件

- 人物资产Skill合集.json：一次导入三套。
- 竖版四宫格.json、竖版五宫格.json、横版人物资产.json：按需单独导入。

在其他兼容版本中，进入“技能 → 导入 Skill”选择 JSON 文件，确认用途为“人物生图”。当前版本内置规则与导入规则完全相同时会去重。不要将多宫格技能分配给“分镜生图”，否则可能让单镜头画面变成设定拼图。
