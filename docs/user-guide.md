# Lum · 影纪使用教程

本教程以 Windows 桌面版为例。第一次使用时，可以拿一个两人对话的小场景走一遍，从写第一场戏到拍出一个预演镜头。

## 安装与进入项目

1. 打开 [Lum 的发布页](https://github.com/ZxzZhao6668/Lum-OpenSource/releases)。有 Windows 版本时，在 **Assets**（附件）里下载文件名以 `Lum-Setup-` 开头、以 `-x64.exe` 结尾的 Windows 安装程序。
2. 运行安装程序，按向导安装，从开始菜单打开 **影纪Lum**。
3. 首页选 **写作**，新建或打开项目。已有剧本要先处理文字时，从这里开始；要直接搭场景，从首页选 **无限画布**。

## 写一场戏，导出交稿文件

1. 在写作项目的 **章节目录** 点 **＋** 增加一章，在剧本编辑区输入正文。
2. 将光标放在一段文字里，用上方工具栏指定 **场次**、**动作**、**角色** 或 **对白**。同一段台词和说这句台词的人各占一段。例如：

   | 段落类型 | 示例内容 |
   | --- | --- |
   | 场次 | 内景　修表铺　傍晚 |
   | 动作 | 门铃响了。阿宁把一块停走的表放上柜台。 |
   | 角色 | 阿宁 |
   | 对白 | 它每天都停在六点十分。 |

3. 长章节可以用 **查找本章** 定位关键词。检查正文后等待保存提示，点右上 **导出稿件**，在导出窗口选择需要的内容与格式。Word 适合继续修改，PDF 适合定稿通读。
4. 如需备份整个写作项目，在项目管理中打开 **项目 / 备份**。交稿文件和项目备份用途不同，建议各保存一份。

## 把文稿带进画布

1. 打开 **无限画布**，进入要使用的画布，再点右上 **写作文稿**。
2. 选中来源项目，切换 **剧本正文**、**大纲**、**场次** 或 **分镜**。展开条目可先核对内容；也可以搜索章节、标题或正文。
3. 点条目右侧 **＋** 放入这一条，或勾选多条后点 **将所选条目放入画布**。画布会出现可打开编辑的文本节点。可先只放入上例的修表铺场次，方便和后续镜头并排查看。
4. 如果列表为空，确认来源项目已保存对应类型的内容，再点 **刷新**。

## 白模预演与拍摄

1. 在画布中添加 **白模预演** 节点，打开场景编辑器。在左侧 **素材** 放入人物或物件，安排好相对位置，再点 **拍摄**。
2. 在取景画面用 **W / A / S / D** 移动，拖动鼠标转向。按 **Q / E** 调整机位高度。鼠标放在画面或焦距条上滚动即可连续变焦，也可点击预设焦距。
3. 点左侧拍法按钮或按 **Tab** 选拍法。拍对话时可以先用固定机位对准柜台，再录一个靠近手表的镜头。
4. 按 **R** 开始录制，再按一次结束。录制中按 **P** 暂停或继续。按 **B** 打开 **已拍素材**，选中一条拍次回放。
5. 在素材面板点 **导出**，按需要选择界面提供的保存或发送到画布选项。正式关闭项目前，打开导出的文件，核对画幅、时长和取景。

## 浏览与分享画布

点击画布底部「帮助」右侧的 **画布分享**。在「浏览作品」中选一个作品查看节点和内容，或点「导入为副本」继续编辑。「分享当前画布」可以选择随作品公开的文字和媒体，投稿文件在 GitHub 上经维护者合并后收录。[作品库与投稿步骤](../canvas-gallery/README.md)

## 配置 AI

打开 **设置 → 文本模型**，配置自己要使用的语言模型，用于写作 Agent 和文本任务。生成图片、视频或音频时，在 **媒体模型** 里添加相应供应商，并在对应节点选择支持该任务的模型。请求由所选供应商处理，费用以供应商账户为准。

## 反馈、入群与合作

在画布底部打开 **？**，点 **汇报 BUG**、**加入交流群** 或 **商务合作**。三个入口都使用 Lum 的微信联系二维码。扫完码后按弹窗提示备注来意。反馈问题时可以附上软件版本、操作步骤和截图。

## 从软件里再次找到教程

在画布底部点击 **？ → 使用教程**。需要下载安装包或查看版本说明时，打开 **设置 → 关于**，进入 **Lum GitHub 仓库** 的 **Releases**。
