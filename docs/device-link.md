# Lum 设备互联

设备互联让另一台电脑或 Android 设备使用共享电脑上的画布项目、模型配置和计算资源。已有项目保存在原设备上，连接期间请保持共享电脑运行 Lum。

## 获取客户端

打开 [Lum 的 GitHub 发布页](https://github.com/ZxzZhao6668/Lum-OpenSource/releases)，在对应版本的 **Assets** 中查看可下载的平台。Android 客户端支持 Android 8 及以上的 ARM64 设备。如果该版本没有 APK 附件，可以使用 Lum 桌面客户端连接另一台电脑。开发者可查看 [Android 客户端的构建说明](../vendor/lum/apps/mobile/readme.md)。

## 在同一局域网内配对

1. 在有项目的电脑上打开画布的 **设置 → 设备互联**，打开 **允许其他设备连接**。
2. 将另一台设备接入同一局域网，打开 Lum 画布首页侧栏的 **设备互联**。用摄像头扫描共享电脑上 **连接新设备** 的二维码，核对设备名称后确认。
3. 手动连接时，在另一台设备上选 **手动输入**，填入共享电脑显示的 **连接地址** 和 **12 位配对码**，点 **连接**。二维码与数字码共用一次配对机会。连接下一台设备时，在共享电脑上点 **连接另一个设备**。

配对成功后，共享电脑的 **设备连接状态** 会列出对方。连接失败时，核对两台设备能否在局域网内互访，并在共享电脑的 **高级选项** 中确认局域网地址及互联端口。默认端口为 `43123`，电脑防火墙需要允许该端口在当前局域网内通信。

## 断开或撤销

在客户端点首页侧栏的连接状态，选择 **断开并独立运行**，即可回到本机项目。要终止某台设备的访问权限，在共享电脑的 **设备连接状态** 中对该设备点 **撤销**。
