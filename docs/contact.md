# 联系 Lum · 影纪

在画布底部点 **？**，选择对应入口即可看到联系方式。

<a id="bug"></a>
## 汇报 BUG

遇到可以重复出现的问题，在 **？ → 汇报 BUG** 扫码联系，或在 [GitHub Issues](https://github.com/ZxzZhao6668/Lum-OpenSource/issues) 先搜索是否有人已经反馈。新建问题时请写出 Lum 版本、操作系统、触发问题的步骤，以及预期结果和实际结果。附上一段经过脱敏的示例文稿或截图有助于复现。请遮挡 API 密钥和私人项目内容。

<a id="community"></a>
## 加入交流群

打开 **？ → 加入交流群**，微信扫码添加联系人，备注「Lum 入群」。这个二维码用于添加联系人，入群需要由联系人邀请。

<a id="business"></a>
## 商务合作

打开 **？ → 商务合作**，微信扫码后备注「Lum 合作」，简要说明用途、希望交付的内容和联系方式。涉及报价、合同和内部素材时，请通过私聊沟通。
